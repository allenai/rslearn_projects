# Landsat vessel detection

The pipeline (`predict_pipeline.py`, served by `api_main.py`) runs a detector over a
Landsat scene, then a classifier over a crop around each detection to drop false
positives, then an attribute model on the kept detections. Paths in `config.py` are
relative to the repo root, so run everything from there. See `ai2_docs/landsat_vessels/`
for the model card and the training and evaluation docs.

## Classifier configs

In `data/landsat_vessels/`:

- **`config_classifier_20260908.yaml`**: the config of the v1.0.0 Landsat model, currently
  in production (run `olmoearth_base_layerdecay_20260908d`). `config.py` and the
  `Dockerfile` point at it. Operating point: detector `score_threshold=0.7`, classifier
  `positive_class_threshold=0.99`.
- **`config_classifier_20260928.yaml`**: the same recipe retrained with the Skylight
  feedback data added (`feedback_20260911` and `feedback_20260928` groups). Generated by
  `feedback/add_to_training.py`.
- **`config_classifier.yaml`**: the legacy Swin classifier, kept for reference only.

## Sub-modules

- **Classifier labels** live in the classifier dataset
  (`/weka/dfive-default/rslearn-eai/datasets/landsat_vessel_detection/classifier/dataset_20250624`),
  one group per labelling source:
  - `selected_copy`, `phase2a_completed`, `phase3a_selected`: annotations from the
    original recheck process, before this tooling existed.
  - `feedback_20260325`: round-0 Skylight feedback (the validation set).
  - `round1_20260803`: round-1 annotations made with `annotations/`.
  - `feedback_<date>`: production false positives added by `feedback/`.
- **`annotations/`**: the annotation app for labelling detector candidates, focused on hard
  negatives, and the record of annotation round 1. `scripts/` has the two steps that
  prepare its input.
- **`feedback/`**: the monthly loop that pulls false positives flagged in the Skylight app,
  turns them into `feedback_<date>` windows, generates a dated training config, and
  publishes the retrained checkpoint.
- **`evaluation/get_metrics.py`**: detector-level precision/recall against ground truth.

## v1.0.0 classifier training results (2026-09-08)

Trained on `selected_copy` + `phase2a_completed` + `round1_20260803` (3,487 windows: 1,525
correct / 1,962 incorrect) and validated on `feedback_20260325` (441 windows: 149 correct /
292 incorrect). Metrics are for the `correct` class at the best `val_correct_f1` epoch.
The deployed recipe is crop 32 / patch 2; the other rows are ablations.

| Recipe | Accuracy | Correct recall | Correct precision | Correct F1 |
|--------|----------|----------------|-------------------|------------|
| **crop 32 / patch 2 (deployed)** | **0.918** | 0.905 | 0.870 | **0.887** |
| same, frozen encoder | 0.899 | 0.872 | 0.860 | 0.866 |
| crop 16 / patch 1 | 0.899 | 0.899 | 0.821 | 0.858 |
| crop 64 / patch 4, no `phase2a_completed` | 0.883 | 0.932 | 0.742 | 0.826 |
| crop 64 / patch 4 | 0.877 | 0.892 | 0.767 | 0.825 |
| crop 64 / patch 4, no `round1_20260803` | 0.848 | 0.966 | 0.647 | 0.775 |

Resolution and patch size matter most (+0.06 F1 from 64/4 to 32/2), and the round-1
annotations are worth ~0.05 F1.

## Smoke test results (2026-09-08)

Full pipeline with the v1.0.0 classifier at detector 0.9 / classifier 0.9; all 7 scenes
pass. The scene list and expected ranges are in `ai2_docs/landsat_vessels/train_eval.md`.

| Scene | Description | Expected | Detections |
|-------|-------------|----------|------------|
| LC09_L1GT_129107 | Mostly ice | [0, 10] | 0 |
| LC09_L1TP_001090 | Mostly whitecaps | [0, 10] | 0 |
| LC09_L1TP_193021 | Some vessels | [20, 50] | 40 |
| LC09_L1TP_170084 | Some vessels | [20, 50] | 39 |
| LC09_L1TP_177081 | Mostly whitecaps | [0, 10] | 3 |
| LC09_L1TP_010012 | Islands + ice | [0, 10] | 2 |
| LC09_L1TP_193030 | Some vessels | [20, 100] | 85 |

Total detections over the 7 scenes, by detector threshold (rows) and classifier threshold
(columns):

```
 det\cls  0.30  0.50  0.70  0.90  0.95
    0.50   236   231   227   222   217
    0.70   214   210   207   204   199
    0.90   174   172   171   169   165
    0.95   153   151   150   148   146
```

The detector threshold is the main knob; the classifier's probabilities cluster near 0
and 1, so its threshold barely changes the count. That is why the deployment pairs a
lower detector threshold (0.7, to keep confident vessels in the 0.7-0.9 band) with a
strict classifier threshold (0.99) as the false-positive filter.
